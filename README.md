# 🛍️ Work Shopping Microservices — Frontend

Interface web do e-commerce [Work Shopping Microservices](https://github.com/RavikFerreira/work-shopping-microservices), desenvolvida com **React** e **TypeScript**. A aplicação consome a API REST do backend para gerenciamento de produtos, carrinho e pagamentos.

---

## 🚀 Tecnologias

| Categoria | Tecnologias |
| --- | --- |
| Biblioteca de UI | React 19 |
| Linguagem | TypeScript |
| Rotas | React Router |
| Requisições HTTP | Axios |
| Testes | Testing Library (React, DOM, Jest DOM) |
| Build e scripts | Create React App (`react-scripts`) |

---

## ✅ Pré-requisitos

- Node.js e npm instalados.
- Backend em execução. Veja as instruções em [work-shopping-microservices](https://github.com/RavikFerreira/work-shopping-microservices).

---

## ▶️ Como executar

```bash
# 1. Clone o repositório
git clone https://github.com/RavikFerreira/work-shopping-microservices-frontend.git

# 2. Entre na pasta
cd work-shopping-microservices-frontend

# 3. Instale as dependências
npm install

# 4. Inicie em modo de desenvolvimento
npm start
```

A aplicação abre em http://localhost:3000.

> **Atenção:** o Grafana do backend também usa a porta 3000. Se os dois estiverem rodando ao mesmo tempo, inicie o frontend com `PORT=3001 npm start`.
